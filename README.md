# Generator Liczb Pseudolosowych

Projekt generatora liczb pseudolosowych wykonany przy użyciu Vite (React + JavaScript).

## Funkcje
- Generowanie liczb pseudolosowych
- Prosty i przejrzysty interfejs
- Aplikacja webowa oparta o React

## Technologie
- Vite
- React
- JavaScript
- CSS


